# Capie · Matematika SD, SMP, dan SMA Kelas 1–12 (termasuk Tingkat Lanjut)

Media pembelajaran matematika berbentuk PWA: setiap materi berupa animasi
bercerita (dimulai dari pertanyaan, dijawab dengan benda yang bisa dilihat),
diikuti soal latihan yang menjelaskan letak keliru setiap jawaban salah.
Anak ditemani maskot robot **Capie** dari daftar akun sampai latihan soal.
(Nama lama produk ini: Easy Math.)

- Kelas 1: 8 bab, 18 materi animasi, 150 soal.
- Kelas 2: 8 bab, 17 materi animasi, 143 soal.
- Kelas 3: 5 bab, 13 materi animasi, 106 soal.
- Kelas 4: 6 bab, 14 materi animasi, 116 soal.
- Kelas 5: 6 bab, 14 materi animasi, 116 soal.
- Kelas 6: 8 bab, 17 materi animasi, 143 soal.
- Kelas 7: 9 bab, 34 materi animasi, 266 soal.
- Kelas 8: 8 bab, 25 materi animasi, 199 soal.
- Kelas 9: 6 bab, 18 materi animasi, 144 soal.
- Kelas 10: 8 bab, 27 materi animasi, 213 soal.
- Kelas 11 (matematika umum): 4 bab, 13 materi animasi, 103 soal.
- Kelas 11 Tingkat Lanjut: 5 bab, 15 materi animasi, 120 soal.
- Kelas 12 (matematika umum): 3 bab, 12 materi animasi, 93 soal.
- Kelas 12 Tingkat Lanjut: 5 bab, 15 materi animasi, 120 soal.
- Soal terdiri dari soal latihan per materi, pertanyaan "tebak dulu" di dalam
  animasi, dan soal tambahan untuk uji bab.
- Ukuran HP, tablet, dan laptop. Tema terang dan gelap.
- Bisa dipasang ke layar utama dan dipakai offline setelah kunjungan pertama.
- Narasi tampil sebagai teks. Kalau perangkat punya suara Bahasa Indonesia
  (Web Speech API), narasi juga dibacakan.
- Progres disimpan di perangkat (localStorage), tanpa akun dan tanpa server.

## Menjalankan di komputer

Tidak perlu build atau `npm install`. Cukup server statis untuk folder `web/`:

```sh
python3 -m http.server 8765 --directory web
```

Buka http://localhost:8765. Service worker hanya aktif di `localhost` atau HTTPS.

## Deploy ke Vercel

1. Di Vercel, pilih **Add New → Project**, lalu impor repo `dimfadd/easy-math`.
2. **Framework Preset: Other**. Kosongkan Build Command dan Install Command.
3. `vercel.json` sudah mengarahkan output ke folder `web`. Kalau Vercel tetap
   menampilkan daftar file repo, ubah **Root Directory** menjadi `web`.
4. Pilih branch yang berisi website ini sebagai Production Branch
   (saat ini `claude/peaceful-faraday-coz3ok`), atau gabungkan dulu ke branch utama.

`.vercelignore` mengecualikan folder riset (`ig-analysis/`) dan `tests/` dari upload.

## Maskot Capie

`capie(mood, { size, say })` di `web/js/capie.js` menghasilkan HTML Capie, dengan
atau tanpa balon ucapan. Capie yang masuk ke halaman langsung bergerak sendiri,
dan `setMood(el, mood)` mengganti reaksinya. Suasana hati yang tersedia:

- `idle`, `hi`, `talk`, `think`;
- `yes`, `no`, `cheer`;
- `fly`, `land`, `oops`;
- `worried`, `surprised`, `sleepy`;
- `yesLoop`, `noLoop` (versi berulang untuk etalase di halaman jual).

**Capie sebagai pemandu.** Setiap `capie()` adalah tempat hinggap, kecuali yang
diberi `guide: false`. Hanya ada satu Capie, dan ia berpindah begini:

- Capie terbang melengkung (pose terbang, menghadap arah tujuan) ke tempat hinggap
  terbaru yang terlihat di layar.
- Ia mendarat dengan pose debu, lalu balon ucapannya muncul.
- Ini berlaku di halaman yang sama (misalnya dari soal ke kotak umpan balik), saat
  halaman digulir, maupun saat pindah halaman.

Interaksi lain:

- Capie disentuh: ia bereaksi bergiliran (mengedip, bersorak, melambai).
- Tidak ada aktivitas 40 detik: Capie tertidur, lalu kaget saat dibangunkan.

Efek gerak ada di `web/js/fx.js`:

- debu mendarat;
- percikan jawaban benar;
- konfeti;
- hati;
- garis kecepatan.

Efeknya digambar di satu kanvas transparan yang hanya aktif selama ada efek.
Rumusnya diadaptasi dari
[claude-animation-skill](https://github.com/buildwithhanif/claude-animation-skill)
(MIT, lisensi di `web/licenses/`).

Bila pengguna memilih "kurangi gerakan", Capie tidak terbang dan tampil diam.

**Efek suara Capie** (`web/js/sfx.js`):

- Bunyi robot 8-bit saat Capie lepas landas dan mendarat. Bunyinya disintesis
  dengan Web Audio, tanpa berkas audio.
- Hanya berbunyi di halaman materi, latihan, dan uji bab.
- Tombol robot di kontrol pemutar materi dan di kepala latihan menyalakan atau
  mematikan efek suara. Pilihan disimpan di perangkat (`settings.sfx`).

Tempat Capie muncul dan aturan pemakaiannya ada di `docs/arah-produk.md`
bagian 10.

## Akun, langganan, dan sinkronisasi (versi pengembangan)

Alamat utama:

- `#/coba`: 9 materi gratis (3 SD, 3 SMP, 3 SMA, diatur di `js/config.js`).
- `#/masuk` dan `#/daftar`: masuk dan daftar.
- `#/profil`: pilih anak yang belajar.
- `#/belajar`: peta belajar.
- `#/ortu`: dasbor orang tua atau guru.
- `#/paket`: paket dan pembayaran.
- `#/akun`: akun dan langganan.

Akun demo (kata sandi `demo123`; PIN anak `1234`):

| Akun | Isi |
|---|---|
| ortu@demo.id | orang tua, langganan Keluarga aktif, anak: raka (kelas 3), nadia (kelas 8) |
| ortu.baru@demo.id | orang tua tanpa langganan, anak: dimas (kelas 5), untuk mencoba alur bayar |
| siswa@demo.id | siswa SMA mandiri dalam masa uji coba |
| guru@demo.id | guru dengan kelas 7A berisi ayu, bima, citra |

Semuanya masih tiruan: "server" adalah `js/mockdb.js` yang menyimpan data di localStorage
perangkat. Kunci materi dan kata sandi diperiksa di browser, jadi **belum aman untuk pengguna
sungguhan**. Saat server siap, cukup ganti isi `js/api.js` dengan panggilan ke endpoint;
halaman lain hanya memakai fungsi di file itu. Hal yang wajib dipindah ke server:
- pemeriksaan kata sandi;
- hak akses materi (materi berbayar tidak boleh ikut terunduh sebelum dibayar);
- konfirmasi pembayaran lewat webhook gerbang pembayaran.

Sinkronisasi dibuat offline-first (`js/sync.js`): progres ditulis ke perangkat dulu, dikirim
sesudah jeda singkat, dan dicoba lagi saat online. Saat masuk, data perangkat dan server
digabung (`mergeProgress` di `js/api.js`), bukan saling menimpa.

Harga di `js/config.js` adalah contoh dan perlu diputuskan sendiri.

## Dua bahasa

Tombol ID/EN di kanan atas mengganti bahasa. Antarmuka dan semua judul, deskripsi, serta
kalimat pembuka materi sudah dua bahasa. Narasi dan soal dalam bahasa Inggris baru tersedia
untuk Kelas 1 Bab 6; materi lain diputar dalam bahasa Indonesia dengan catatan.

Menerjemahkan satu bab: buat `content/en/<id-bab>.js` mengikuti contoh `content/en/k1b6.js`
(indeks bagian, langkah, dan soal sama dengan isi aslinya), tandai materi dengan `full: true`,
lalu daftarkan di `content/en/index.js`. Teks di panggung yang berupa kata diterjemahkan lewat
`els: { idElemen: 'teks' }`. Kunci jawaban tidak perlu diubah: jawaban siswa berbahasa Inggris
dibaca dengan koma ribuan dan titik desimal.

## Menulis atau mengubah materi

Satu materi berisi beberapa bagian (`chapters`). Setiap langkah (`steps`) punya
narasi `say` dan mengubah panggung 400 × 300 dengan `add`, `set`, `del`, atau
`clear`. Pemutar menganimasikan perbedaan antarlangkah secara otomatis.

```js
{
  say: 'Pasangkan biru dengan merah. Ada 3 pasangan nol.',
  add: [box('pr0', 110, 146, 36, 92, { dash: '5 4' })],
  set: { q: { text: '{p:5} + ({n:−3}) = {p:2}' } },
  ask: { options: [{ t: '2', ok: true }, { t: '8', why: 'Penjelasan kenapa salah' }] },
}
```

Warna di teks: `{p:…}` biru (positif), `{n:…}` merah (negatif), `{a:…}` kuning,
`{g:…}` hijau. Pangkat: `2{^:5}` (tidak boleh di dalam markup warna). Setiap opsi salah wajib punya `why`. Soal isian memakai
`type: 'num'` dengan `ans` (bisa menerima pecahan, desimal koma, 112.000, awalan Rp, dan akhiran % atau kg).

Setelah mengubah isi, naikkan `VERSION` di `web/sw.js` supaya perangkat yang
sudah memasang aplikasi mengambil versi baru.

Jalankan server lokal dulu, lalu:

```sh
BASE=http://localhost:8765/ node tests/smoke.cjs     # semua halaman, semua langkah, 3 ukuran layar
node tests/answers.mjs                                # pemeriksa jawaban isian
BASE=http://localhost:8765/ node tests/offline.cjs   # service worker dan mode offline
BASE=http://localhost:8765/ OUT=shots node tests/shots.cjs && sh tests/sheets.sh shots
```

`smoke.cjs` memeriksa error, overflow horizontal, objek keluar panggung, teks
bertumpuk, objek kosong, id bentrok, dan soal tanpa kunci atau tanpa penjelasan.
Butuh Node 18+ dan paket `playwright`.
