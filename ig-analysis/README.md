# ig-analysis

- `SINTESIS.md` — temuan gabungan dan resep untuk website (baca ini dulu)
- `01_De3AtMHTGaK.md` — analisis mendalam video viral akalmatika
- `data/<akun>_posts.json` — metadata post + 15 komentar terbaru
- `transcripts/<akun>__<shortCode>.md` — transkrip bertimestamp (Whisper Turbo via Apify)
- `frames/<akun>/<shortCode>/hook` — 0–3 dtk, 4 fps; `timeline` — 1 frame/2 dtk (t_001 = 0 dtk)
- `sheets/<akun>__<shortCode>.jpg` — contact sheet 1 frame/4 dtk
- `HANDOFF.md` — catatan serah terima antar sesi
